# HelpDesk TI

Prototipo de mesa de ayuda basado en ITIL 4 para registrar, priorizar, asignar y dar seguimiento a las incidencias y solicitudes del área de Tecnología.

Proyecto aplicado del curso **Gerencia de Proyectos Informáticos** – CUN, 2026.

**Página en línea:** https://yulian-9.github.io/HelpDesk-TI/

**Docente:** Osmany Aley Martínez

## Módulos

1. **Registro de tickets.** Formulario con un cronómetro que mide el tiempo de registro.
2. **Prioridad y asignación.** Matriz impacto × urgencia (P1 a P4) con acuerdos de nivel de servicio (ANS).
3. **Seguimiento de estados.** Nuevo → Asignado → En curso → En espera → Resuelto → Cerrado, con historial.
4. **Base de conocimiento.** Soluciones a los casos frecuentes.
5. **Tablero de indicadores.** Tickets por estado, prioridad, categoría y técnico; cumplimiento de ANS.

## Cómo usarlo

Abre la página en línea desde cualquier navegador. Todo el equipo ve los mismos tickets y los cambios aparecen en tiempo real.

La prueba piloto se realizó el 5 de noviembre de 2026 con casos reales del área de TI registrados por el equipo.

## Tecnologías

- HTML5, CSS3 y JavaScript
- Chart.js para los gráficos
- Supabase (PostgreSQL) como base de datos en la nube, con actualización en tiempo real
- GitHub Pages para publicar la página
